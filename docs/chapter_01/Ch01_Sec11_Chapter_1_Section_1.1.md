### **二、核心物理机制与严密公式推导**

**1\. 气体状态方程全族 (State Equation Family)**  
大气在通常温压条件下可精确视为理想气体。状态方程具有多种表达形式：  
• **微观分子形式**：p = n k\_B T，其中 n 为数密度（m⁻³），玻尔兹曼常数 k\_B = 1.38065 × 10⁻²³ J/K。  
• **摩尔形式**：p V = n\_m R\* T，摩尔数 n\_m = m / M，通用气体常数 R\* = 8.31447 J/(mol·K)。  
• **比容形式**：p α = R T，比容 α = 1 / ρ（m³/kg），气体常数 R = R\* / M。  
• **密度形式**：p = ρ R T。  
具体大气成分常数：  
干空气平均分子量 M\_d ≈ 28.966 g/mol，干空气比气体常数 R\_d = R\* / M\_d = **287.05 J/(kg·K)**；  
水汽分子量 M\_v = 18.015 g/mol，水汽气体常数 R\_v = R\* / M\_v = **461.51 J/(kg·K)**；  
两气体常数之比：**ε = M\_v / M\_d = R\_d / R\_v ≈ 0.622**，倒数 **1/ε = M\_d / M\_v ≈ 1.608**。  
**2\. 湿空气表观气体常数与虚温 (Virtual Temperature) 全套严密推导**  
湿空气是干空气与水汽的混合气体。根据道尔顿分压定律：总压 p = p\_d + e，总密度 ρ = ρ\_d + ρ\_v。  
展开总密度：ρ = p\_d / (R\_d T) + e / (R\_v T) = (p - e) / (R\_d T) + e / (R\_v T) = [p - (1 - ε)e] / (R\_d T)。  
若将湿空气当作具有表观气体常数 R\_m 的气体：p = ρ R\_m T，可求得 **R\_m = R\_d (1 + 0.608 q)**。  
为保持干空气气体常数 R\_d 不变，引入虚温 T\_v 使得：p = ρ R\_d T\_v。  
• **精确解析解**：T\_v = T / [1 - (1 - ε)(e / p)] = T / [1 - 0.378 (e / p)]。  
• **一阶级数展开（基于水汽压 e）**：因 e \ll  p，利用 (1 - x)⁻¹ ≈ 1 + x，得 T\_v ≈ T [1 + 0.378 (e / p)]。  
• **比湿 q 表达形式**：代入 q ≈ ε (e / p)，计算系数 (1 - ε)/ε = 1/ε - 1 = (28.966 - 18.015) / 18.015 = **0.608**！因此 **T\_v = T (1 + 0.608 q)**。  
• **混合比 w 表达形式**：因 q = w / (1 + w) ≈ w，故 **T\_v ≈ T (1 + 0.608 w)**。  
• **虚温增量 ΔT\_v**：ΔT\_v = T\_v - T = 0.608 q T。常温（q ≈ 15 g/kg，T ≈ 300 K）下，ΔT\_v 可达 2\~3 K，在浮力计算与静力学方程中不可忽略。  
**3\. 大气湿度参数方程全集与相互转换**  
• **水汽压 e 与饱和水汽压 E**：水汽产生的分压（hPa）。  
• **绝对湿度 a (g/m³)**：a = ρ\_v = e / (R\_v T)。单位换算推导：a = [e · 10² / (461.51 · T)] · 10³ = (10⁵ / 461.51) · (e / T) = **216.7 (e / T)**。  
• **比湿 q (g/g 或 g/kg)**：q = m\_v / (m\_d + m\_v) = ρ\_v / ρ = [ε e / T] / [[(p - e) + ε e] / T] = **ε e / [p - (1 - ε)e] ≈ ε (e / p)**。  
• **混合比 w (g/g 或 g/kg)**：w = m\_v / m\_d = ρ\_v / ρ\_d = **ε e / (p - e)**。  
• **q 与 w 的互算公式**：**q = w / (1 + w)**，**w = q / (1 - q)**。  
• **相对湿度 f (%)**：f = (e / E) × 100% ≈ (w / w\_s) × 100% ≈ (q / q\_s) × 100%。  
• **饱和差 d (hPa)**：d = E - e = E (1 - f)。  
• **露点温度 T\_d (°C 或 K)**：气压不变且水汽含量未变时，空气冷却至达到饱和时的温度。当 e = E(T\_d) 时成立。  
• **劳伦斯 (Lawrence) 近似公式**：相对湿度与露点差（T - T\_d）关系：**f ≈ 100 - 5 (T - T\_d)**（当 f > 50% 时精度极高）。  
**4\. 克劳修斯-克拉佩龙方程 (Clausius-Clapeyron) 与冰水面饱和水汽压**  
由热力学第一与第二定律推导相变平衡方程：dE / dT = L / [T (α\_v - α\_l)]。因 α\_v \gg  α\_l 且 α\_v = R\_v T / E，可得微分形式：  
**d ln E / dT = L / (R\_v T²)**  
积分形式（假设潜热 L 为常数）：E(T) = E\_0 exp[(L / R\_v) (1/T\_0 - 1/T)]。  
气象学常用经验公式（马格努斯-泰藤斯 Magnus-Tetens）：  
水面：E\_w(t) = 6.112 exp[17.67 t / (t + 243.5)]  (t 以 °C 计)；  
冰面：E\_i(t) = 6.112 exp[22.46 t / (t + 272.62)]。  
**冰水面差异与贝吉隆过程 (Bergeron Process)**：由于冰升华潜热 L\_s 大于水汽化潜热 L\_v，在负温（t < 0 °C）下，水分子克服分子间力脱离液面比脱离冰面更容易，故 **E\_w > E\_i**（在 -12\~-15 °C 处 ΔE = E\_w - E\_i 达到最大）。在冷云中，当实际水汽压 e 满足 E\_i < e < E\_w 时，环境对水滴未饱和（水滴蒸发），对冰晶过饱和（水汽凝华至冰晶），导致冰晶快速长大、水滴消失。  
**5\. 大气垂直分层与结构 (Vertical Structure)**  
大气总质量 **M\_atm ≈ 5.27 × 10¹⁸ kg**。按温度垂直递减率 γ = -dT/dz 可分为五层：  
• **对流层 (Troposphere)**：平均厚度赤道 17\~18 km、中纬度 10\~12 km、极地 8\~9 km。集中了全大气 **78% 以上的质量** 和几乎全部水汽。平均温度递减率 **γ ≈ 6.5 °C/km**，对流运动旺盛，天气现象复杂。  
• **平流层 (Stratosphere)**：对流层顶至 50\~55 km。集中了大气中大部分臭氧（O₃），在 20\~30 km 形成臭氧层。O₃ 强烈吸收太阳紫外辐射产生增温，形成深厚逆温（上暖下冷），大气稳定，以平流运动为主。  
• **中间层 (Mesosphere)**：平流层顶至 85 km。无 O₃ 加热，CO₂ 强辐射冷却，温度随高度急剧下降，顶部达到全大气最低温（约 -90 °C / 180 K）。  
• **热层 (Thermosphere)**：中间层顶至 800 km。O₂、N₂ 吸收极紫外辐射强烈增温，温度可达上千开尔文，气体处于高度电离状态（电离层）。  
• **散逸层 (Exosphere)**：800 km 以上，气体稀薄，分子平均自由程极大，轻气体分子（H、He）可逃逸入行星际空间。

**三、典型例题与计算标准**

**综合计算例题**：某气象站测得气压 p = 1000.0 hPa，温度 t = 27.0 °C (T = 300.15 K)，相对湿度 f = 80%。已知 27 °C 时饱和水汽压 E = 35.67 hPa。求：(1) 实际水汽压 e；(2) 混合比 w 与比湿 q；(3) 绝对湿度 a；(4) 虚温 T\_v；(5) 真实湿空气密度 ρ 并与忽略湿度计算的密度比较。  
**标准步骤与解答**：  
1\) e = f · E = 0.80 × 35.67 hPa = **28.54 hPa**。  
2\) w = ε e / (p - e) = 0.622 × 28.54 / (1000.0 - 28.54) = 0.01827 kg/kg = **18.27 g/kg**；  
   q = w / (1 + w) = 0.01827 / 1.01827 = 0.01794 kg/kg = **17.94 g/kg**。  
3\) a = 216.7 (e / T) = 216.7 × (28.54 / 300.15) = **20.60 g/m³**。  
4\) T\_v = T (1 + 0.608 q) = 300.15 × (1 + 0.608 × 0.01794) = **303.42 K (30.27 °C)**。  
5\) 真实密度 ρ = p / (R\_d T\_v) = (100000 Pa) / (287.05 J/(kg·K) × 303.42 K) = **1.1482 kg/m³**。  
   若误用实际温度 T 计算：ρ\_dry = p / (R\_d T) = 100000 / (287.05 × 300.15) = 1.1607 kg/kg³。相对误差达 (1.1607 - 1.1482) / 1.1482 ≈ **+1.09%**（高估了空气质量）。
